## Целевая архитектура (утверждена HEAD 04.11)
- **Адрес:** `app.artgame.world`, тестовый `test.app.artgame.world`. HTTPS через Caddy.
- **Где:** текущий VPS, отдельный пользователь и systemd-служба приложения, лимит памяти. Шлюз и задачи FIN03/SRC02/DRIVE01 не трогаем.
- **База:** PostgreSQL 16 — главный источник данных. Ничего не удаляется, только помечается «отменено». Журнал действий (кто, что, когда).
- **Сервер:** Python 3.12 + FastAPI. Для Битрикса — существующая библиотека сервера (`tools/lib/bitrix.py`: замок записи, сверка после записи).
- **Экран:** React + Vite, одна сборка для Mini App и PWA; дизайн-система «как игра» (токены, персонажи отделов из design-kit, тёмная/светлая тема). Работа без сети на объекте (очередь отправки).
- **Вход:** Telegram initData (подпись токеном бота) → человек → роль и зоны из базы.
- **Копии:** ночной pg_dump на Google Диск + снимок VPS у Hoster.kz; проверка восстановления раз в месяц.
- **Выкладка:** push в main → GitHub Actions → тест → основной. HEAD ничего не вставляет руками.

## Роли и зоны
Роли: Саппорт, Художник, Художник Про, Главный художник (их несколько), Оператор настенного принтера, Мастер настенной печати, МОП, VIP МОП, Главный дизайнер, Помощник дизайнера, HEAD.
Зоны: Роспись, Печать, Дизайн, Продажи; у человека может быть несколько, в смене выбирает зону.
Проверяют: Главный художник — роспись, Мастер печати — печать, Главный дизайнер — дизайн, HEAD — всё, ГИП — свой объект.

## Порядок разделов
1. Смены и расходы (как в прототипе) — первым.
2. МОП (из артефакта) → производство (печать + художники одним местом) → дизайн.
3. Игра и знания: опыт только за подтверждённое, уровни = роли, очки и пороги в константах; экзамены из реестра знаний.
4. Финансы HEAD, выплаты «к выплате / выплачено».
5. Запись в Битрикс через одобрение.
