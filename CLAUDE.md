# Правила для работы с репозиторием

- Пользователь — HEAD. Писать по-русски, коротко.
- Секретов в репозитории нет и не будет: токен бота живёт в свойствах скрипта Apps Script (BOT_TOKEN) и в переменной среды ARTGAME_BOT_TOKEN.
- `index.html` и `server/Index.html` держать одинаковыми (страница сама определяет, откуда открыта).
- Сначала читать `ARCHITECTURE.md`.
- Сервер (`server/`) выкладывается сам: push в main → GitHub Actions `deploy-server.yml` (clasp) обновляет развёртывание, адрес /exec не меняется. HEAD ничего не вставляет вручную. Проверять результат выкладки: `gh api repos/Raman-Artgame/artgame-app/actions/runs`.
- Перед выкладкой прогонять сквозной тест страницы с моками Apps Script (Playwright).
- Константы ARTGAME (цены, ставки) в приложение не вшивать — только из листа «Значения» таблицы констант.
- Записи в Битрикс — только через Кодекса и «да» HEAD.
