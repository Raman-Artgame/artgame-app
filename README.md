# ARTGAME — приложение команды (Telegram Mini App)

Открывается кнопкой в боте @artgame_team_bot.

- `index.html` — страница приложения (публикуется на GitHub Pages).
- `server/Code.gs` — сервер на Google Apps Script, привязан к Таблице «Журнал работ» (Диск ARTGAME HEAD). Вставляется в Apps Script вручную.
- `server/Index.html` — та же страница для открытия напрямую из Apps Script (запасной вариант).

Данные: Google Таблица «Журнал работ» (листы Люди, Объекты, Смены, Расходы, Справочник, Сводка, Журнал действий).
Фото и чеки: общий Диск → ПРОЕКТЫ → год → месяц → «№ сделки · НАЗВАНИЕ — ГОРОД» → «Журнал работ (фото и чеки)».
Цифры ARTGAME — только из «КОНСТАНТЫ ARTGAME KZ», здесь не дублируются. В Битрикс приложение не пишет.
